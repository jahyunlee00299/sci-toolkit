# Less common routes

| The user asks for… | Route (in order) | Gate before you call it done |
|---|---|---|
| Preprints / "has this been posted yet" / 최신 논문 검색 (search for recent papers) | `biorxiv-database` (Europe PMC `SRC:PPR` + arXiv) | 🔒 Hits are **not peer reviewed**: say so, and cite the published DOI when the skill reports one. |
| Collect references + OA PDFs for a DOI list | `scripts/ref_fetch.py` | 🔒 Read `refs_report.json`: report `discrepancies` and `not_found` explicitly; never silently pick one source. |
| Turn a manuscript into a Korean patent invention disclosure (발명내용설명서) | `patent-invention-disclosure` | 🔒 `patent-invention-disclosure/scripts/verify_numeric_claims.py` on every claim number before final. UNRESOLVED is not a pass. |
| A reported number needs a `±`, a unit conversion (mM/µM, mg/mL via MW) or a calibration-curve concentration; "SD or SEM?"; error propagation, 오차 전파, 불확도, 단위 변환 | `uncertainty-and-units` (→ `scientific-validation` for the fit itself) | 🔒 `uncertainty-and-units/scripts/propagate_uncertainty.py` or `uncertainty-and-units/scripts/format_result.py`, never a hand-typed ±. Package absent = say the check could not run. |
| Plan an experiment before running it: ≥2 factors, a plate layout, "how many replicates", 실험 설계, DoE, 반복수, 플레이트 배치 | `doe-and-replication` → `experiment-hub` (pipetting workbook) | Name the replicate level (technical vs independent prep); record seed, pydoe version and run table in the `lab-record` EXP. |
| Make slides | figures first via `publication-figures` → `journal-ppt` + the office skill your agent ships (see the note below the table) | Numbers and claims traced to their source (§3). Slide figures are finished image files, never plotted by the slide skill. |
| Convert a file (PDF/docx/xlsx → md) | `markitdown`, `paper-extract` (or the external `pdf`/`xlsx` skill) | Spot-check the output against the source; conversion silently drops content. |
| Search the live web | `research-search` → built-in WebSearch / WebFetch | Cite sources; separate what a source said from your inference. No API key is needed. |
| Set up / install / "it's not working" | `doctor.py` | 🔒 `python doctor.py` must print `PASS` — quote the failing line, don't paraphrase. |
| Molecular weight / band size / pI of an expressed or tagged protein, from a plasmid map ("분자량 계산", "몇 kDa", "밴드 크기") | `sequence-verification` → `sequence-verification/scripts/construct_mw.py` | 🔒 `sequence-verification/scripts/construct_mw.py <map> --native-start <motif>` exits 0. Label figures computed, not measured. |
| "Which file carries this variant" / find the expected sequence to align a sequencing read against / which primer reaches the mutation ("시퀀스 파일 찾아", "시퀀싱 대조", "변이 확인용 맵") | `sequence-verification` → `sequence-verification/scripts/find_variant_maps.py` → `sequence-verification/scripts/primer_codons.py` → `sequence-verification/scripts/build_reference_map.py` → `sequence-verification/scripts/read_coverage.py` | 🔒 `sequence-verification/scripts/find_variant_maps.py --expect <residue>=<AA>`: only a translated residue is evidence. `sequence-verification/scripts/read_coverage.py` exits 0 before a primer is ordered. |

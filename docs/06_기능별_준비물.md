# 06. 기능별 준비물 — "이 기능 쓰려면 뭘 준비하나요?"

> 결론부터: **대부분의 기능은 아무 준비 없이, 구독 로그인만으로 바로 됩니다.**
> API 키나 별도 설치가 필요한 건 몇 개뿐이고, 그마저도 대개 **공짜로 우회하는 길**이 있습니다.
> 이 문서는 "어떤 기능이 뭘 요구하는지"를 한 장으로 정리한 준비물 표입니다.

앞선 문서 연결: 개념은 [02_API와_MCP](02_API와_MCP.md), 외부 서비스 연동·보안은
[05_외부서비스_연동](05_외부서비스_연동.md), 실제 연동 스크립트는
[`scripts/connectors/README.md`](../scripts/connectors/README.md) 를 보세요.

---

## 1. 네 가지 준비물 종류

기능마다 필요한 게 다른데, 딱 네 종류뿐입니다.

| 표시 | 뜻 | 초심자 부담 |
|---|---|---|
| 🟢 **구독만** | Claude/ChatGPT 구독 로그인만 되어 있으면 바로 됨 | 없음 |
| 🔑 **API 키** | 특정 서비스 키가 필요 (대부분 무료 대안 있음) | 낮음~중간 |
| 🔌 **MCP 연결** | 앱에서 서비스 "연결" 또는 작은 서버 실행 필요 | 중간 |
| 🛠 **로컬 도구** | 컴퓨터에 프로그램 설치 필요 (LibreOffice 등) | 중간 |

> 대부분은 🟢입니다. 아래 표에서 🟢가 아닌 것만 눈여겨보면 됩니다.

## 2. 기능별 준비물 표

### 🟢 그냥 되는 기능들 (준비물 없음)

구독 로그인만으로 바로 쓰는 기능입니다. **대부분이 여기에 속합니다.**

| 기능(스킬) | 하는 일 | 비고 |
|---|---|---|
| `research-lookup` | 논문 조회 (OpenAlex+PubMed) | 무료, 키 불필요 (스킬이 직접 명시) |
| `openalex-database` | OpenAlex 논문 DB | 완전 공개, 키 불필요 |
| `pubmed-database` | PubMed 검색 | 키 없이 동작 (키는 속도만 향상, 선택) |
| `biorxiv-database` | 프리프린트 검색 (bioRxiv·medRxiv·arXiv) | 무료, 키·가입 불필요 |
| `stats-workflow` | 통계 검정·리포팅 | 파이썬 패키지만 |
| `scientific-validation` | 결과 타당성 검증 | 표준 라이브러리 |
| `academic-term-rules` | 용어·표기 규칙 | 규칙 문서(실행 없음) |
| `lab-data-analysis` | 랩 데이터 분석·안전정보 | PubChem 무료 API |
| `paper-extract` | 논문에서 표·그림·본문 추출 | 이미 설치된 라이브러리 |
| `research-ideation` | 아이디어·가설 | 순수 사고 워크플로우 |
| `research-search` | 검색 메타 라우터 (논문·프리프린트·웹) | 전부 무료, 키 불필요 |
| `pdf` | PDF 조작 (기본 기능) | 순수 파이썬 (OCR만 예외 ↓) |

### 🔑 API 키가 필요한 기능 (일부만, 대부분 무료 길 있음)

| 기능 | 뭐가 필요 | 필수? | 무료 우회 |
|---|---|---|---|
| `markitdown` | 파일→마크다운 | 선택 | 기본 변환은 **완전 무료**. AI 이미지 설명 기능만 OPENROUTER 키 |
| `literature-review` | 문헌고찰 문서 | 선택 | Semantic Scholar는 무료 티어 존재(키 권장). 검색·문서 생성 자체는 됨 |

> 🔑 키를 넣는 법은 [02_API와_MCP](02_API와_MCP.md)와 커넥터의
> `config/credentials.example.json` 방식(환경변수)을 참고하세요. **급하지 않으면 키 없이
> 무료 경로부터 써보시길 권합니다.**

### 🔌 MCP 연결이 필요한 기능

| 기능 | 뭐가 필요 | 필수? |
|---|---|---|
| `primer-design` | 로컬 MCP 서버 실행 (`python -m src.primer_design.mcp_server`) | **필수** — 이 스킬은 MCP 서버로 동작 |

> MCP가 뭔지는 [02_API와_MCP](02_API와_MCP.md)의 "표준 플러그" 비유를 보세요.
> primer-design은 프라이머 설계 도구가 작은 서버로 떠야 작동합니다 — 설정법은 그 스킬의
> SKILL.md에 있습니다. 잘 모르면 관리자에게 "primer-design MCP 어떻게 켜요?" 물어보세요.

### 🛠 로컬 프로그램 설치가 필요한 기능

| 기능 | 설치할 것 | 언제 필요 |
|---|---|---|
| `xlsx` | **LibreOffice** | 엑셀 수식 재계산·검증 시 (단순 읽기/쓰기는 불필요) |
| `docx` | `pandoc`, **LibreOffice**, (최종 검증은 Windows+MS Word) | 문서 변환·트랙변경 반영·손상 최종검증 |
| `literature-review` | `pandoc` + LaTeX(xelatex) | **PDF로 출력할 때만** (마크다운 산출은 불필요) |
| `endnote-citation-injection` | **EndNote 2025 + 라이브러리 파일** | 이 기능 자체가 EndNote에 의존 |
| `publication-figures` | `scikit-image` (pip) | 그림 재구성(Route 5)만 |

> 🛠 이 프로그램들은 대부분 랩 PC에 이미 깔려 있는 경우가 많습니다. 없으면 해당 기능을
> 쓸 때만 설치하면 되고, 나머지 기능엔 지장 없습니다.

## 3. 외부 서비스(메일·GitHub·Asana·Notion·캘린더·시트)는?

이건 스킬이 아니라 **연동**이라 [05_외부서비스_연동](05_외부서비스_연동.md)에서 따로 다룹니다.
요약하면:
- **연결**: `scripts/connectors/`의 REST 커넥터가 기본값 → 🔑(토큰) 또는 캘린더·시트는 OAuth
  1회 동의. 앱의 "연결하기" 버튼(MCP)은 REST로 대체 못 하는 탐색성 작업에만 최후의 수단.
- **스크립트로 쓰려면**: `scripts/connectors/`의 커넥터 + `config/credentials.json`(환경변수).
- ⭐ **나가는 건 초안까지만** — 메일 발송·삭제 같은 건 항상 확인/이중잠금.

## 3-2. 용량은 얼마나 되나요?

배포판 **전체가 약 5MB**밖에 안 됩니다 (USB에 바로 들어갑니다). 골라 설치하면 더 작습니다.
`python install/install.py --list` 를 실행하면 각 기능·프리셋의 용량이 표시됩니다.

- **무거운 편**: `docx`(1.4MB) · `xlsx`(1.2MB) · `primer-design`(697KB) — 이 3개가 큰 축.
- **대부분**: 4~130KB로 매우 가볍습니다.
- **프리셋 예**: 논문 작성 820KB · 문헌 조사 281KB · 데이터·그림 332KB · 문서 작업 2.8MB · 전체 5MB.

> 용량 때문에 고민할 필요는 거의 없습니다 — 다 합쳐도 5MB입니다. 골라 담기는 용량보다
> "안 쓰는 기능으로 어수선해지지 않게" 하려는 목적이 큽니다.

## 4. 그래서 처음엔 뭘 하면 되나요?

1. **아무것도 준비하지 말고** 구독 로그인만 된 상태에서 🟢 기능부터 써보세요
   (논문 검색·통계·데이터 분석·figure 등 — 이게 대부분입니다).
2. 어떤 기능이 "키가 필요하다/서버를 켜라"고 하면, 그때 이 문서 표에서 그 줄을 찾아
   **무료 우회가 있는지** 먼저 확인하세요. 대개 있습니다.
3. 정말 필요한 키·설치만 그때그때 준비하면 됩니다. 미리 다 갖출 필요 없습니다.

막히면 이 문서 표의 해당 줄을 캡처해서 랩 선배(관리자)에게 물어보세요.

## 한 줄 요약

- **거의 다 🟢 구독만으로 바로 됨** — 미리 준비할 게 없습니다.
- 🔑 **API 키**가 필요한 건 소수(research-search 유료백엔드·markitdown 이미지·literature-review) — 대부분 **무료 우회 존재**.
- 🔌 **MCP**는 `primer-design`(로컬 서버, 필수) 정도.
- 🛠 **로컬 설치**는 `xlsx`/`docx`(LibreOffice)·`literature-review`(PDF용 LaTeX)·`endnote`(EndNote)뿐.
- 원칙: **필요할 때 그 기능 것만 준비**하면 됩니다 — 처음부터 다 갖추지 마세요.

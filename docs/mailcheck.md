# mailcheck: 한국어 학술 메일 문체 검사기

보내기 전의 메일 초안을 규칙으로 검사해서 "이 문장은 고치세요"를 알려 주는 작은 도구입니다.

## 이 도구가 하지 않는 일

- 메일을 보내지 않습니다. 초안 텍스트 파일만 읽습니다.
- AI(LLM)를 쓰지 않습니다. 정해진 규칙(정규식과 숫자 비교)만 씁니다. 같은 글은 항상 같은 결과가 나옵니다.
- 인터넷에 접속하지 않습니다. 메일함(IMAP)에도 접속하지 않습니다.
- 글을 대신 고쳐 쓰지 않습니다. 어디가 문제인지만 알려 줍니다.

## 준비물

Python 3.10 이상이면 됩니다. 추가로 설치할 패키지는 없습니다. (설정 파일을 직접 바꾸려면 Python 3.11 이상이 필요합니다.)

## 가장 간단한 사용법

1. 메일 초안을 `draft.txt`로 저장합니다 (UTF-8).
2. sci-toolkit 폴더에서 실행합니다.

```
python -m mailcheck draft.txt
```

결과 예:

```
[필수 수정] apology (사과 횟수): 사과가 2회 (최대 1회)
[권고] ai_tell (AI 말투): AI 말투: '말씀드리겠습니다'
```

- `[필수 수정]`이 하나라도 있으면 종료 코드 1, 없으면 0입니다. `[권고]`만 있으면 0입니다.
- 파일을 못 읽는 등 실행 자체가 실패하면 종료 코드 2입니다.

## 옵션

| 옵션 | 뜻 |
|---|---|
| `--source received.txt` | 받은 메일 텍스트. 숫자 검사와 되풀이 검사에 필요합니다 |
| `--recipient person` 또는 `admin` | 받는 사람이 개인인지 행정 부서인지 (기본 person) |
| `--owner-edited` | 내가 직접 고친 글이면 붙입니다. 대부분의 필수 수정이 권고로 내려갑니다 (내부 메모, 마크다운은 그대로 필수) |
| `--profile profile.json` | 받는 사람의 말투 프로필 (아래 "말투 프로필" 참고) |
| `--config my.toml` | 내 설정 파일 (아래 "설정 바꾸기" 참고) |

## received.txt 쓰는 법 (숫자 검사용)

숫자, 날짜, 금액은 "받은 메일에 있는 것만" 써야 합니다. 그래서 받은 메일의 본문을 그대로 복사해 `received.txt`에 붙여 넣습니다. 제목, 첨부 파일 이름, 메신저로 받은 지시처럼 숫자의 출처가 되는 글도 같은 파일에 이어서 붙이면 됩니다.

```
제목: 11월 시약 구매 견적 확인 요청
수정된 견적서 사본과 책임자 확인 후 진행 결과를 알려 주십시오.
결제 금액은 1,200,000원 입니다. 마감은 11월 20일 입니다.
첨부: 견적서_수정본.pdf
```

`received.txt`를 안 주면 초안에 금액이나 날짜가 있는 순간 "출처 없음"으로 지적합니다.

## 검사 항목과 예시

### apology (사과 횟수)

사과는 메일 전체에서 한 번까지만 씁니다 (죄송, 미안, 송구, 사과드).

- 걸리는 글: `죄송합니다. 회신이 늦었습니다. 정말 송구합니다.`
- 괜찮은 글: `회신이 늦어 죄송합니다. 자료를 첨부합니다.`

### gratitude (감사 횟수)

감사는 맺음에 한 번, 본문에 한 번까지만 씁니다.

- 걸리는 글: 본문에서 `감사드립니다`를 두 번 쓰고 마지막 줄에서 또 `감사합니다`
- 괜찮은 글: 본문 `확인해 주셔서 감사합니다.` + 맺음 `감사합니다.`

### summary_echo (받은 메일 되풀이)

받은 메일에 쓰여 있는 내용을 다시 요약하는 문장은 상대가 이미 아는 말이라 뺍니다. 받은 메일과 단어가 60% 이상 겹치는 긴 문장(6단어 이상)을 찾습니다.

- 걸리는 글: `수정된 견적서 사본과 책임자 확인 후 진행 결과를 알려 주셔야 한다고 하셨습니다.`
- 괜찮은 글: `수정된 견적서 사본과 책임자 확인 후 진행 결과를 알려 드리겠습니다.`

"~하겠습니다, ~드리겠습니다, ~예정입니다"로 끝나는, 내가 하겠다고 약속하는 문장은 요청의 단어를 그대로 써도 허용됩니다. 단 `좋겠습니다`, `알겠습니다`처럼 약속이 아닌 `~겠습니다`는 허용되지 않습니다.

### unsourced_number (출처 없는 숫자)

초안의 금액, 날짜, 5자리 이상 번호가 `received.txt`에 없으면 지적합니다. 금액은 표기가 달라도 같은 값으로 봅니다: `1,200,000원`, `120만원`, `1.5억원`, `3천만원`.

- 걸리는 글: (받은 메일에 1,200,000원만 있을 때) `결제 금액은 150만원입니다.`
- 괜찮은 글: `결제 금액은 120만원입니다.` (1,200,000원과 같은 값)

### admin_reasoning (행정 수신자에게 판단 설명)

`--recipient admin`일 때만 검사합니다. 행정 담당자에게는 결과와 필요한 요청만 쓰고, 내 판단의 이유를 설명하지 않습니다.

- 걸리는 글: `제 판단으로는 이번 건은 재료비가 맞습니다.`
- 괜찮은 글: `이번 건은 재료비로 처리 부탁드립니다.`

### internal_note (내부 메모 흔적)

초안 쓰다가 남긴 메모가 본문에 남아 있으면 지적합니다. `--owner-edited`로도 낮아지지 않습니다.

- 걸리는 글: `자료 보냅니다. (확인 필요)`, `[TODO]`, `(초안)`
- 괜찮은 글: `자료 보냅니다. (첨부 참조)`

### markdown (마크다운 문법)

메일은 일반 글자로 씁니다. `**굵게**`, `# 제목`, `` `코드` ``, `[링크](https://...)`를 쓰면 지적합니다. 이것도 `--owner-edited`로 낮아지지 않습니다.

- 걸리는 글: `**중요** 확인 바랍니다.`
- 괜찮은 글: `중요한 건이라 확인 부탁드립니다.`

### profile_* (받는 사람 말투)

`--profile`을 줄 때만 검사합니다. 받는 사람이 평소 쓰는 말투와 다르면 지적합니다: `profile_register`(존댓말/반말), `profile_honorific`(호칭), `profile_signoff`(서명 어미 올림/드림), `profile_exclaim`(맺음 느낌표), `profile_language`(한국어/영어).

- 걸리는 글: 평소 "교수님"이라 부르는 사람에게 호칭 없이 `자료 보낼게`
- 괜찮은 글: `안녕하세요, 김 교수님. 자료를 보냅니다. 이도윤 드림`

### ai_tell (AI 말투)

`말씀드리겠습니다`, `~하는 바입니다`, `소중한 의견`, `아울러/더불어/이에 따라` 반복 같은 AI 글투를 찾습니다. 항상 권고 수준입니다.

## 말투 프로필 (선택)

내가 그 사람에게 보냈던 메일 몇 통(최대 5통)에서 말투를 뽑아 JSON으로 저장해 두면 `--profile`로 쓸 수 있습니다. 메일함에 접속하는 기능은 없으므로 메일 본문은 직접 파일로 저장합니다.

```python
import json
from mailcheck.voice import SentSample, extract_profile

samples = [SentSample("1", "2026-01-05", "자료 요청", open("sent1.txt", encoding="utf-8").read())]
profile = extract_profile("prof@example.edu", samples)
json.dump(profile.to_dict(), open("profile.json", "w", encoding="utf-8"), ensure_ascii=False)
```

## 설정 바꾸기

`mailcheck/mailcheck.toml`에 기본값이 있습니다. 복사해서 `--config my.toml`로 쓰거나 환경 변수 `MAILCHECK_CONFIG`에 경로를 적습니다. 바꿀 수 있는 것:

- `[admin]` 행정 부서로 볼 주소 앞부분(`office`, `support` 등)과 이름 단어(`센터`, `행정` 등)
- `[voice]` 서명 어미 목록(`올림`, `드림`)과 호칭 목록
- `[thresholds]` 되풀이 판정(6단어, 60%), 사과 최대 횟수, 감사 최대 횟수
- `[internal_note]` 내 작업 방식에 맞는 메모 패턴 추가

## 자주 묻는 질문

- 결과가 너무 엄격해요: 직접 고친 글이면 `--owner-edited`를 붙이세요.
- 한글이 깨져 보여요: 초안 파일을 UTF-8로 저장했는지 확인하세요.
- 같은 규칙이 승인 대기함 쪽 검사기와 조금 다를 수 있습니다. 이 도구는 독립된 복사본이고, 이름과 소속이 들어간 개인 설정은 뺐습니다.

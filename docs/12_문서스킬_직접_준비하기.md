# 12. 문서 스킬(docx·pdf·pptx·xlsx) 직접 준비하기

이 툴킷에는 `docx`, `pdf`, `pptx`, `xlsx` 스킬이 **들어있지 않습니다.**
빠뜨린 게 아니라 넣을 수 없어서입니다.

## 왜 빠져 있나요

이 네 스킬은 Anthropic이 만들어 배포하는 것이고, 함께 오는 `LICENSE.txt`가
다음을 명시적으로 금지합니다.

> - Extract these materials from the Services or **retain copies of these materials
>   outside the Services**
> - **Distribute**, sublicense, or transfer these materials to any third party

즉 이 저장소에 복사본을 담아 두는 것 자체가 라이선스 위반입니다. 저장소가
비공개(private)여도 마찬가지입니다 — "Services 밖에 사본을 보관하지 말라"는
조항은 공개 여부와 무관하기 때문입니다.

그래서 **파일은 빼고, 연결은 남겼습니다.** 설치 프로그램은 이 스킬들에 대한
의존 관계를 그대로 알고 있고, 필요할 때 위 사실을 알려줍니다.

## 어떻게 준비하나요

**대부분의 경우 아무것도 하지 않아도 됩니다.**

Claude Code에게 "이 워드 파일 고쳐줘", "PDF에서 표 뽑아줘", "엑셀로 정리해줘"
라고 하면, 해당 문서 형식을 다루는 능력은 Claude Code 쪽에서 제공됩니다.
이 툴킷이 그 자리를 채울 필요가 없습니다.

만약 문서 작업이 잘 안 된다면, Anthropic이 제공하는 경로로 해당 스킬을 받아
`~/.claude/skills/` 아래에 두세요. 배포 경로는 Claude Code 버전에 따라 다르므로
여기에 특정 링크를 적어두지 않습니다 — 오래된 링크가 더 헷갈리기 때문입니다.

## 그래도 이 툴킷으로 할 수 있는 원고 작업

원고 QC·편집 도구 중 **이 랩에서 직접 만든 것들**은 그대로 들어 있습니다.
`docx` 스킬 폴더 안에 있었을 뿐, Anthropic 코드가 아니어서 `manuscript-pipeline`
으로 옮겨 두었습니다.

| 도구 | 하는 일 |
|---|---|
| `manuscript_text.py` | 추적 변경(tracked changes)이 있는 docx에서 **올바른** 텍스트 추출. python-docx는 삽입분을 조용히 누락합니다 — `--count-only`로 먼저 확인하세요 |
| `word_com_ops.py` | Word COM 기반 편집 — 변경내용 확정, run 경계를 넘는 find-replace, 캡션 교체, 표 셀 수정 |
| `word_live_edit.py` | 사용자가 Word로 **열어둔 문서**를 실시간 편집 (Windows + pywin32 필요) |
| `manuscript_ref_order.py` | Figure/Table 인용 순서 진단 |
| `figure_caption_check.py` | 캡션↔그림 정합 QC (번호·인용순서·라벨) |
| `endnote_biblio_check.py` | 인용된 번호마다 서지 항목이 실제로 있는지 |
| `visual_check.py` | 문서를 페이지별 PNG로 렌더 — 레이아웃을 눈으로 확인 |

전부 `skills/manuscript-pipeline/scripts/` 에 있습니다. 예:

```bash
python skills/manuscript-pipeline/scripts/manuscript_text.py MANUSCRIPT.docx --count-only
# exit 10 = 추적 변경 있음 → --mode accept 로 추출할 것

python skills/manuscript-pipeline/scripts/figure_caption_check.py MANUSCRIPT.docx
```

이 도구들은 python-docx(PyPI, 오픈소스)만 있으면 동작하고, Anthropic 스킬에
의존하지 않습니다.

## 요약

| | 상태 |
|---|---|
| `docx`·`pdf`·`pptx`·`xlsx` 스킬 본체 | 저장소에 없음 (Anthropic 소유) |
| 문서 형식 처리 능력 | Claude Code 가 제공 — 보통 그냥 됩니다 |
| 랩 자체 제작 원고 QC 도구 7종 | `manuscript-pipeline/scripts/` 에 그대로 있음 |
| 설치 프로그램 | 의존 관계를 알고 있고, 빠진 것을 알려줍니다 |

# 15. Git과 GitHub 설정하기

sci-toolkit은 GitHub 저장소(https://github.com/jahyunlee00299/sci-toolkit)에서 받습니다. 저장소는 공개라서 계정이 없어도 받을 수 있습니다. 계정이 필요한 때는 이슈를 남기거나 변경을 올릴 때뿐입니다.

스킬을 설치하는 명령(`python install/install.py`)은 저장소 폴더 안의 파일을 `~/.claude/skills/` 같은 곳으로 복사합니다. Claude Code를 쓰든 Codex를 쓰든 상관없고, 저장소 폴더가 컴퓨터에 있기만 하면 됩니다. 그 폴더를 받는 방법이 이 문서의 주제입니다.

---

## 1. 받는 방법 고르기

| 상황 | 방법 |
|---|---|
| Git이 낯설다, 한 번만 받으면 된다 | 저장소 페이지에서 Code → Download ZIP |
| 나중에 업데이트를 받고 싶다 | `git clone` (2~5번) |
| 이슈를 남기거나 변경을 올린다 | `git clone` + GitHub 로그인 (2~5번) |

ZIP으로 받았다면 압축을 푼 폴더가 `sci-toolkit` 폴더입니다. ZIP에는 `.git`이 없어서 `git pull`로 갱신할 수 없고, 새 버전이 나오면 다시 받아야 합니다. ZIP으로 받은 경우에는 6번으로 건너뛰세요.

## 2. Git 설치

- Windows: [git-scm.com/download/win](https://git-scm.com/download/win)에서 설치 파일을 받아 기본값으로 설치합니다. 터미널에서는 `winget install --id Git.Git -e`도 됩니다.
- macOS: 터미널에서 `git --version`을 입력합니다. Git이 없으면 개발자 도구 설치 창이 뜹니다.

설치가 끝나면 확인합니다.

```bash
git --version
```

버전이 나오면 됩니다. 설치 직전에 열어 둔 터미널은 새 설정을 모르므로, `git`을 못 찾는다고 나오면 터미널을 닫고 다시 여세요.

## 3. Python 확인

`install.py`와 `doctor.py`는 Python 3.10 이상에서 돌아갑니다.

```bash
python --version
```

없거나 낮으면 [python.org/downloads](https://www.python.org/downloads/)에서 설치합니다. Windows 설치 화면에서는 "Add python.exe to PATH"를 체크하세요.

## 4. GitHub 계정과 로그인 (선택)

받기만 할 거라면 건너뛰어도 됩니다. 이슈를 남기거나 변경을 올리려면 [github.com/signup](https://github.com/signup)에서 계정을 만들고, 아래 둘 중 하나로 로그인합니다.

- GitHub CLI: Windows는 `winget install --id GitHub.cli`, macOS는 `brew install gh`로 설치한 뒤 `gh auth login`을 실행합니다. 질문이 나오면 GitHub.com, HTTPS, Login with a web browser를 고르고, 터미널에 나온 코드를 브라우저 창에 입력합니다. `gh auth status`로 로그인 여부를 확인합니다.
- GitHub Desktop: [desktop.github.com](https://desktop.github.com)에서 설치하고 앱에서 로그인합니다. 명령어 없이 저장소를 받고 갱신할 수 있습니다.

비밀번호나 토큰은 채팅창과 코드에 붙여넣지 마세요. 토큰을 다루는 방법은 [05_외부서비스_연동](05_외부서비스_연동.md)에 있습니다.

## 5. 저장소 받기

```bash
git clone https://github.com/jahyunlee00299/sci-toolkit.git
cd sci-toolkit
```

OneDrive 같은 동기화 폴더 안에는 두지 마세요. `.git` 폴더가 동기화되는 중에 저장소가 깨지는 일이 있습니다. Windows라면 `C:\Users\<사용자이름>\sci-toolkit`처럼 홈 폴더 바로 아래가 무난합니다.

## 6. 스킬 설치

방금 들어간 `sci-toolkit` 폴더에서 실행합니다.

```bash
python install/install.py --list
python install/install.py --preset paper-writing --apply
python doctor.py
```

`doctor.py`가 `PASS`를 내면 준비된 것입니다. Claude Code는 새 세션을 열어야 설치한 스킬을 읽습니다. 어떤 스킬을 고를지는 [QUICKSTART](../QUICKSTART.md)와 [01_설치와_첫_명령](01_설치와_첫_명령.md)을 보세요.

설치는 복사입니다. 저장소를 갱신해도 이미 복사된 스킬은 바뀌지 않으므로, 갱신 뒤에는 `install.py`를 다시 실행해야 합니다.

## 7. 업데이트

```bash
cd sci-toolkit
git pull
python install/install.py --preset paper-writing --apply
python doctor.py
```

`install.py`는 이미 있는 파일을 지우지 않고, 같은 이름의 파일만 새 버전으로 바꿉니다.

## 8. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `git`을 찾을 수 없다고 나온다 | 터미널을 닫고 새로 엽니다. 그래도 안 되면 Git을 다시 설치합니다 |
| `python`을 찾을 수 없다 | Python 설치 프로그램을 다시 실행하면서 "Add python.exe to PATH"를 체크합니다 |
| `git clone`이 repository not found를 낸다 | 주소를 위의 것 그대로 복사했는지 확인합니다 |
| `git pull`이 local changes would be overwritten를 낸다 | 폴더 안 파일을 직접 고친 경우입니다. 고친 파일을 다른 곳에 복사해 둔 뒤 `git restore <파일>`을 하고 다시 `git pull`합니다 |

막히면 연구실 동료에게 오류 메시지를 그대로 보여 주세요. 메시지 전체가 있으면 원인을 찾기 쉽습니다.

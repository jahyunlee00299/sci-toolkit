# 00. 시작하기 — AI 에이전트가 처음이신 분께

이 문서는 **AI 에이전트를 한 번도 써본 적 없는 초심자**를 위한 안내문입니다.
어려운 말 없이, 비유로 설명합니다. 천천히 읽어보세요.

---

## 1. "AI 에이전트"가 뭔가요?

지금까지 써보신 ChatGPT나 Claude 채팅창은 "질문하면 답해주는" 도구였습니다.
**AI 에이전트**는 여기서 한 단계 더 나아간 겁니다.

> 비유: 채팅 AI가 "전화로 물어보면 답해주는 상담원"이라면,
> AI 에이전트는 **"내 컴퓨터 앞에 앉혀놓은 신입 연구원"** 입니다.

이 신입 연구원은:
- 폴더 안 파일을 직접 열어보고 읽을 수 있고,
- 엑셀/코드/문서를 직접 고칠 수 있고,
- 명령을 실행해서 그래프를 그리거나 데이터를 정리할 수 있습니다.

즉, "말로 설명 듣고 → 제가 손으로 다 하는" 게 아니라
"시키면 → 그 신입 연구원이 직접 컴퓨터를 조작해서 끝내놓는" 방식입니다.

물론 아무거나 막 하지는 않습니다. 파일을 지우거나 중요한 걸 바꾸기 전에는
"이렇게 해도 될까요?" 하고 먼저 물어보도록 되어 있습니다 (설정에 따라 다름).
처음에는 옆에서 지켜보시다가, 믿을 만하다 싶으면 점점 맡기시면 됩니다.

---

## 2. 이 툴킷(sci-toolkit)은 뭘 해주나요?

우리 연구실에서 반복적으로 하는 작업들 — 실험 데이터 정리, 그래프 그리기,
논문 검색, 문서 작업, 코드 디버깅 등 — 을 AI 에이전트가 **일관된 방식으로**
도와주도록 미리 준비해둔 설정 모음입니다.

> 비유: 신입 연구원에게 매번 "우리 실험실은 이런 식으로 그래프 그려" 라고
> 처음부터 설명할 필요 없이, **이미 그 규칙을 알고 있는 상태로** 출근시키는 것과 같습니다.

그래서 여러분은 "이 데이터로 그래프 그려줘" 라고만 말해도,
우리 실험실 스타일에 맞는 결과물이 나옵니다.

---

## 3. Claude Code가 뭔가요? (기본 도구)

이 툴킷은 **Claude Code**라는 프로그램 위에서 동작합니다.
Claude Code = 위에서 말한 "AI 에이전트"를 실제로 쓸 수 있게 해주는 프로그램입니다.

### 가장 쉬운 시작 방법: 데스크톱 앱

터미널(까만 화면에 글자 치는 것)이 낯설게 느껴지신다면,
**Claude Code 데스크톱 앱**으로 시작하시는 걸 추천드립니다.

- 일반 프로그램처럼 아이콘을 클릭해서 실행합니다.
- 채팅창처럼 생긴 화면에 그냥 원하는 걸 한국어로 적으면 됩니다.
- "이 폴더에 있는 실험 데이터 요약해줘" 처럼 자연스럽게 말하면 됩니다.

터미널 버전도 있지만, 처음이시라면 데스크톱 앱이 훨씬 편합니다.
나중에 익숙해지시면 자연스럽게 터미널 버전도 눈에 들어올 거예요.

> **Codex로 하려면?**
> Codex는 OpenAI에서 만든 비슷한 종류의 AI 에이전트 도구입니다.
> 우리 툴킷은 기본적으로 Claude Code 기준으로 안내하지만,
> Codex를 쓰고 싶으신 분은 각 문서 하단의 "Codex 팁" 부분을 참고하시면 됩니다.
> 개념(에이전트가 파일을 읽고 고친다는 것)은 동일하고, 실행 방법만 조금 다릅니다.

## 4. 처음 쓰시는 분들을 위한 안심 포인트

- **망가뜨릴까 걱정되시나요?** 대부분의 작업은 파일을 "새로 만들거나" "복사본에 적용" 하는
  방식이라, 원본 데이터가 훼손될 걱정은 크지 않습니다. 그래도 중요한 파일은
  미리 한 번 복사해두시면 마음이 편합니다.
- **명령어를 몰라도 되나요?** 네, 몰라도 됩니다. 그냥 하고 싶은 말을 한국어로 적으시면
  AI가 알아서 필요한 명령을 만들어 실행합니다. "이 폴더 정리해줘", "이 그래프 다시
  그려줘" 처럼요.
- **틀린 질문이란 게 있나요?** 없습니다. 애매하게 말씀하셔도 AI가 되물어봅니다.
  편하게 말씀하시면 됩니다.
- **한 번에 다 이해 안 되셔도 괜찮습니다.** 처음엔 그냥 시켜보고 결과를 보는 것부터
  시작하세요. 쓰다 보면 자연스럽게 감이 잡힙니다.

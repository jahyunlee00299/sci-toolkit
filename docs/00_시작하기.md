# 00. 시작하기 (처음 쓰는 분을 위한 안내)

이 문서는 AI 에이전트를 처음 쓰는 사람을 위한 안내입니다. "그게 뭔데?"부터 설명하고, 읽는 데 10분쯤 걸립니다.

---

## 1. AI 에이전트가 뭔가요?

챗봇은 질문하면 말로 답해 주는 상대입니다. AI 에이전트는 거기서 한 걸음 더 나아가 말만 하지 않고 직접 일을 합니다.

비유하면 이렇습니다.

- 챗봇 = 실험 방법을 말로 알려 주는 선배
- AI 에이전트 = 옆에 서서 파일을 열고, 표를 정리하고, 그래프를 그려 주는 실험 보조원

"이 엑셀 파일에서 반복 평균을 내고 그래프로 그려 줘"라고 평소 쓰는 말로 부탁하면, 에이전트가 컴퓨터 안에서 파일을 읽고, 계산하고, 결과 파일을 만들어 줍니다. 코딩을 몰라도 됩니다.

## 2. 이 sci-toolkit은 뭔가요?

sci-toolkit은 연구실에서 자주 하는 일을 에이전트가 더 잘 해내도록 모아 둔 도구 상자입니다.

- 에이전트가 일반 보조원이라면, 이 도구 상자는 거기에 쥐여 주는 연구실 전용 매뉴얼과 공구입니다.
- 데이터 정리, 그래프 그리기, 통계 확인, 원고 다듬기 같은 일을 "우리 연구실 방식대로" 하도록 안내해 줍니다.
- 각 도구는 사용법이 적힌 설명서와 함께 들어 있어서, 에이전트가 알아서 읽고 따라 합니다. 외울 필요는 없습니다.

## 3. Claude Code가 뭔가요?

[Claude Code](https://code.claude.com/docs/ko/overview)는 [Anthropic](https://www.anthropic.com)의 AI "Claude"를 에이전트로 쓸 수 있게 해 주는 프로그램입니다. 이 도구 상자의 기본 프로그램이고, 위에서 말한 보조원이 사는 곳입니다.

쓰는 방법은 여러 가지인데, 초심자에게는 데스크톱 앱이 가장 쉽습니다.

| 방법 | 어떤 모습인가요 | 추천 |
|---|---|---|
| [데스크톱 앱](https://code.claude.com/docs/ko/desktop-quickstart) | 일반 프로그램처럼 창을 열고 대화 | 처음이라면 이것 |
| [터미널(검은 창)](https://code.claude.com/docs/ko/quickstart) | 글자만 있는 화면에서 명령 입력 | 익숙해진 뒤에 |

### 시작하는 순서

1. [Claude 데스크톱 앱](https://claude.com/download)을 설치하고 로그인합니다. (계정이 없다면 연구실 담당자에게 물어보세요. 요금제는 [여기](https://claude.com/pricing)에서 볼 수 있습니다.)
2. 앱에서 작업할 폴더를 선택합니다. 보조원에게 "이 작업대에서 일하세요"라고 알려 주는 것과 같습니다.
3. 채팅창에 하고 싶은 일을 평소 말투로 적습니다. 예시는 이렇습니다.
   - "이 폴더의 엑셀 파일을 읽고 어떤 데이터가 들어 있는지 알려 줘."
   - "시간별 농도 데이터를 그래프로 그려 줘."
4. 에이전트가 무엇을 하려는지 보여 주면, 내용을 확인하고 **허용**을 누릅니다. ([권한 설명](https://code.claude.com/docs/ko/permissions))

> Codex로 하려면: OpenAI의 [Codex](https://developers.openai.com/codex)도 같은 방식으로 쓸 수 있습니다. [앱](https://developers.openai.com/codex/app)이나 [터미널](https://developers.openai.com/codex/cli)에서 작업 폴더를 열고 똑같이 말로 부탁하면 됩니다. 다만 설정 파일의 이름과 위치가 조금 다르니, [Codex의 AGENTS.md 안내](https://developers.openai.com/codex/guides/agents-md)와 [04. AI에게 규칙 주기](04_AI에게_규칙주기.md)를 확인해 주세요.

## 4. 처음이라면 이것만 기억하세요

- 말로 부탁하면 됩니다. 정해진 문장은 없고, 실험 노트에 쓰듯 편하게 적으면 됩니다.
- 한 번에 하나씩 부탁하면 결과가 더 좋습니다.
- **결과는 꼭 한 번 눈으로 확인하세요.** 에이전트도 가끔 틀립니다. 논문이나 보고서에 들어가는 숫자는 반드시 원본과 맞춰 보세요.
- 모르면 되물어 보세요. "방금 한 일을 쉽게 설명해 줘"라고 하면 풀어서 알려 줍니다.
- 개인정보와 비밀번호는 넣지 마세요. 외부에 공개하면 안 되는 연구 데이터도 조심해 주세요.

## 5. 자주 하는 걱정

- 파일을 망가뜨릴까 봐 걱정된다면: 에이전트는 파일을 바꾸거나 지우기 전에 보통 먼저 허락을 구합니다. 중요한 원본은 복사본을 하나 만들어 두고 시작하세요.
- 코딩을 못한다면: 코드는 에이전트가 씁니다. 무엇을 원하는지만 말하면 됩니다.
- 실수했다면: 되돌릴 수 있는 경우가 대부분입니다. 틀렸으면 "다시 해 줘"라고 하면 됩니다.

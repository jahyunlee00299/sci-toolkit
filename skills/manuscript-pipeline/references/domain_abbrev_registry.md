## Enzyme-name italic rule
- Only the species prefix is italic; the enzyme name itself is roman: `*Ec*XylA` (not *EcXylA*, not EcXylA)
- Variant notation: `*Ec*XylA(G171R/L172R)` or `*Ec*XylA<sup>G171R/L172R</sup>`

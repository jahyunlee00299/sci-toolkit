## 19. Quantity and State Modifiers (vague/imprecise quantity-and-state language) [Manual review required]

far. The other named sub-topics (vague back-references, optimality/extremum language, empty

**Hedging-as-evasion** [Manual review required]: a sentence that states a real result in terms of
falling short of an internally-chosen standard, when the actual value is favorable, undermines the
paper's own finding. Test: if the surrounding numbers show the result is good, does the sentence's
framing make it sound worse than it is? If yes, restate the finding directly (state the value, state
the standard only if the standard itself is load-bearing for the argument) rather than leading with
the shortfall.

| Pattern (avoid) | Fix |
|---|---|
| "X falls short of the Y threshold in some cases" (when X exceeds Y in the reported cases) | State the achieved range directly; only mention the threshold if a real case fails it |
| "a conservative design floor was assumed" (unsupported self-defense) | State what was actually assumed and why, with the number |
| "it should be noted that..." followed by a caveat that contradicts the main claim without new information | Either integrate the caveat's actual content into the main sentence, or delete if it adds nothing the reader needs |

Worked example (generic): a manuscript reports a predicted product-purity range of 99.3–99.5%, then
adds "this falls short of the reference-grade purity threshold of 98% in some cases." Read literally
this sounds like a shortfall, but 99.3% already exceeds 98% — the sentence made a favorable result
sound marginal by leading with a threshold comparison that does not apply. The fix is to state the
achieved range directly ("the predicted purity range, 99.3–99.5%, exceeds the reference-grade
threshold of 98%") and drop the "falls short" framing entirely. The same pattern shows up with
unsupported self-defense phrases like "a conservative design floor was assumed" — replace with the
actual assumption and its numeric basis instead of a defensive label.
